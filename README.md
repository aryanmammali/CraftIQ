
CraftIQ is an AI-powered educational platform that explains how real-world objects are made.

Users can:

* Upload an image 📷
* Enter a text query 💬

The system then provides **step-by-step manufacturing insights** using:

* Computer Vision
* Natural Language Processing

CraftIQ bridges the gap between **theoretical learning and real-world understanding** by combining AI with an interactive web interface.

---

## 🎯 Problem Statement

Students often struggle to understand how everyday objects are manufactured and how they function internally.

Existing resources are:

* Too complex
* Fragmented
* Not interactive

CraftIQ solves this by delivering **simple, structured, and AI-driven explanations**.

---

## 💡 Solution

CraftIQ combines Computer Vision and NLP to generate manufacturing insights.

### Core Capabilities:

* Detects objects from images using AI models
* Accepts user queries in natural language
* Retrieves structured manufacturing data
* Falls back to generative AI when data is unavailable

---

## 🛠️ Tech Stack

### Backend

* Python (Flask)

### AI & Models

* YOLO (Object Detection)
* CLIP (Image-Text Understanding)
* Gemini API (Generative AI fallback)

### Database

* SQLite

### Frontend

* HTML, CSS, JavaScript
